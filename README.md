# 🎓 Sistema de Gestión de Aula

Sistema web para gestión de calificaciones escolares, desarrollado con **.NET 10**, **Blazor Server**, **Entity Framework Core** y **SQL Server**.

## ✨ Características

- 📊 **Dashboard interactivo** con estadísticas generales del aula
- 👥 **Listado de alumnos** con filtros por nombre, DNI y estado
- 📖 **Libreta individual** con los 4 parciales por materia
- ⚠️ **Reporte de cursos desaprobados** con profesor asignado
- 📚 **Resumen por materia** con porcentaje de aprobados
- 🔍 **Búsqueda en tiempo real** en todas las vistas
